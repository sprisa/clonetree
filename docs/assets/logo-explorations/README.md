# Logo explorations

Kept for reference. The current logo is [`../clonetree.svg`](../clonetree.svg):
wire pines with a multiply fill ([`wire-blends/w1-multiply-fill.svg`](wire-blends/w1-multiply-fill.svg)).

Each round, in order:

| Sheet | What it explored |
| --- | --- |
| [1 · First concepts](sheets/1-first-concepts.png) | Fast forward, chevron pine, shared pines, branch, and c-branch, beside the original canopy logo |
| [2 · Shared pines, 80s](sheets/2-shared-pines-80s.png) | Striped, rainbow core, 1-bit and color pixel, phosphor, and sunset versions of shared pines |
| [3 · Phosphor in Apple colors](sheets/3-phosphor-apple-colors.png) | CRT wireframes with each pine in its own early-Apple color |
| [4 · Fabric palette](sheets/4-fabric-palette-styles.png) | Cream, burnt orange, and sage from a 1970s print; wire, solid, and scanline styles on light and dark, with and without tiles |
| [5 · Solid blends](sheets/5-solid-blends.png) | Solid pines with the overlap as multiply, darken, 50% opacity, screen, blend bands, and halftone |
| [6 · Wire blends](sheets/6-wire-blends.png) | Wire pines with the same blend modes, including overprinted line crossings |
| [7 · Terminal art](sheets/7-terminal-art.png) | Darken scanlines, multiply fill, and screen glow drawn with terminal characters |

Blend colors are precomputed rather than using SVG blend modes or opacity, so
each mark looks the same on any background. The SVGs from rounds 4 to 6 are in
[`palette-styles/`](palette-styles), [`solid-blends/`](solid-blends), and
[`wire-blends/`](wire-blends). Earlier rounds survive as sheets only.
